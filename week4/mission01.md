# 리팩토링이란?

겉으로 보이는 기능은 그대로 두고, 코드 내부 구조를 더 좋게 고치는 작업.
추후 유지보수하게 쉽게 하기 위해서 필수적이다.

주의!! 결과가 같아야 리팩토링이다.
새로운 기능이 추가되거나 / 보이는 화면이 예쁘게 바뀌었다면
이는 리팩토링이 아니다.

# 커스텀 훅(Custom Hook)이란?

여러 컴포넌트에서 공통으로 사용하는 로직을 따로 빼서 재사용하는 기능.
코드를 여러번 사용할 경우에 이를 하나로 묶어서 재사용하고 싶을 수 있다. 이때 사용하는게 커스텀 훅!

react에는 hook이라는 함수가 존재한다.

- useState()
- useEffect()
- useRef()
  이런 것들..

react에서는 사용자가 직접 새로운 hook을 만들 수 있게 해준다.
이렇게 만든 hook이 커스텀 훅.

- 커스텀 훅의 핵심은?

* 커스텀 훅은 결국 함수.
* 이름이 use로 시작해야 react에서 hook으로 인식한다.
* 내부에서 또다른 hook을 사용 가능하다.
