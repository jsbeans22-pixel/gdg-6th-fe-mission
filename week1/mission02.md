## html이란??
html은  <시작태그>내용(content)</시작태그> 로 구성됨
<!DOCTYPE html> 을 통해 html5 기준으로 해석하라고 알려준다
<html></html> 로 문서의 시작과 끝을 알려준다
<head></head> 사이에는 웹페이지 메인에는 표시되지 않는 내용들이 들어간다
<body></body> 사이에 웹페이지 화면에 출력되는 요소들을 넣는다
<h1></h1> 제목
<p></p> 내용
<div></div>를 사용해 한 덩어리씩 분리한다

태그 사이에 내용이 없는 요소는 빈 요소 ex) <meta charset="utf-8"> 이며, 어트리뷰트(Attribute)만을 가진다.

어트리뷰트란??
요소를 상세히 정의할때 필요..
ex) <img> 로만은 이미지의 세부정보를 모른다.. 이때 어트리뷰트를 이용해 파일명/경로/크기 등을 표시한다

## 기본 문법
변수를 var로도 선언할 수 있지만.. 요즘은 let, const로 선언

자바스크립트는 7가지 데이터 타입을 제공한다.
원시 타입 (primitive data type)
* number - 숫자(정수/소수 등..)
* string - 문자열, 글자
* boolean - True,False
* null - 값이 없음
* undefined - 없는 값.. 선언만 하고 값 안 넣으면 이렇게 됨
* symbol (New in ECMAScript 6) - 유일한 값 > 객체의 유일한 값으로/절대 겹치지 않음

객체 타입 (Object data type)
* object - 참조 방식으로 저장, 수정 가능

- 원시/객체 타입의 가장 큰 차이는 원시 타입은 값 복사시 서로 영향이 없음(값 자체 저장) / 객체 타입은 같이 바뀐다!(주소 공유) > 파이썬의 Immutable/Mutable 이랑 비슷

연산자/주석/함수,if,for,while문 등 존재

객체 기반의 스크립트 언어로..자바스크립트를 이루고 있는 거의 모든 것이 객체이다..(원시 타입 빼고 나머지는 모두 다 객체)
