# api는 무엇일까?
인터넷에서 데이터를 받아오는 창구.
웹사이트에서 필요한 데이터를 직접 가지고 있지 않기 때문에, 타 서버에게 요청해
이 정보를 받아오게 된다.
이때 사용하는 통로가 api다.

## fetch("~~")
API를 호출하는 자바스크립트 기능이다.
서버에게 데이터를 요청한다.

인터넷은 느리므로 데이터를 받는 데 시간이 걸릴 수 있다.

만약 동기 방식이라면 데이터를 받을 때까지
다른 작업을 하지 못하고 기다려야 한다.

하지만 비동기 방식은 데이터를 요청해놓고,
응답이 오는 동안 다른 작업을 계속 수행할 수 있다.

그리고 데이터가 도착하면,
.then() 등을 통해 필요한 작업을 실행한다.

# fetch 이후의 then이 필요한 이유
fetch는 데이터를 서버에서 가져오는 기능이다.
하지만 인터넷 요청은 시간이 걸리기 때문에 바로 결과를 받을 수 없다.

만약 데이터를 받을 때까지 기다리면 화면이 멈추게 되므로,
비동기 방식을 사용한다.

예를 들어 브라우저가 코드를 위에서 아래로 읽다가 fetch를 만나면:
1. 서버 데이터 요청을 한다.
2. 데이터가 올 때까지 기다리지 않는다.
3. 나머지 코드들을 먼저 계속 실행한다.
4. 데이터가 도착하면 .then() 안의 함수를 실행한다.

따라서 .then()의 역할은:
비동기 작업이 끝난 뒤 실행할 함수를 등록하는 것!
